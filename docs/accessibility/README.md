# Accessibility Guidance

`dyslex.ai` follows these principles:

- preserve meaning and technical detail;
- use short paragraphs;
- use explicit headings;
- avoid ambiguous pronouns;
- expand acronyms when helpful;
- write dates clearly;
- avoid relying only on color, bold, italics, emoji, or alignment;
- never claim that one font, color, or layout works for everyone;
- never diagnose a user.

## Profiles

- `minimal`: light changes and only important ambiguity warnings.
- `balanced`: default, with readable chunks and useful headings.
- `guided`: smaller steps, more context, explicit checks.
- `custom`: user-controlled settings.

## Related W3C Areas

The design aligns with cognitive accessibility guidance and relevant WCAG 2.2 areas such as readable content, headings and labels, error identification, labels or instructions, and consistent help.
